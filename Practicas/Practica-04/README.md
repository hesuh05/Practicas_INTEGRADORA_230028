# Práctica No. 4: Business Model Canvas — LoopPack

## Descripción

Business Model Canvas interactivo para **LoopPack**, una plataforma B2B2C de empaques reutilizables inteligentes para e-commerce. El artefacto fue generado con Archify a partir de un archivo JSON reproducible.

## Entregables

- `loop-pack-business-model-canvas.html`: Canvas interactivo listo para abrirse en un navegador.
- `loop-pack-business-model-canvas.json`: modelo fuente en formato JSON de Archify.
- `render-loop-pack.mjs`: script de generación y validación.

## Vista del modelo

El diagrama presenta los nueve bloques del Business Model Canvas y relaciona la red de socios, la operación circular, los segmentos, los canales y las fuentes de ingresos. Las tarjetas inferiores conservan el detalle operativo de cada bloque.

## Regeneración

Con Node.js y el runtime de Archify disponible, ejecutar:

```powershell
node Practicas/Practica-04/render-loop-pack.mjs
```
